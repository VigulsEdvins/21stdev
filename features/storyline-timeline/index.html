Our story

Five milestones, one long road

Drag the track, use the mouse wheel or the arrow buttons. Each milestone lights up as it reaches the middle.

  1. 2019

    First sketch

    A notebook page and a rough idea for a faster way to build pages.

  2. 2020

    Private beta

    Twenty friendly teams tried it and told us what was confusing.

  3. 2021

    Public launch

    The first stable release, with a library of ready-made sections.

  4. 2023

    Theme engine

    One palette and one font pair now restyle a whole page at once.

  5. 2025

    Export anywhere

    Pages leave as plain HTML, CSS and JavaScript you fully own.
